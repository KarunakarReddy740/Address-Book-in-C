# Address Book Management System in C

## Overview
A contact management application developed in C as part of Embedded Systems training at Emertxe Technologies.

The project organizes contact information and provides functions to create, search, list, and manage contacts.

## Features
- Create and store contact details.
- Search for existing contacts.
- Display the contact list.
- Save contact information to a file.
- Use a menu-driven interface to manage contacts.

## Technologies Used
- C Programming
- Structures
- Functions
- File Handling
- String Processing

## Project Structure
The project is organized into source and header files for contact management, searching, listing, and file operations.

## How to Compile and Run
Compile the program using GCC with the required project source files.

```bash
gcc *.c -o addressbook
```

Run on Linux:

```bash
./addressbook
```

On Windows:

```bash
addressbook.exe
```
